# customer_confirm_skill

## 职责

识别用户请求中的企业名称是否为简称/俗称/歧义名，若是则通过 `ask_user` 向用户确认完整工商全称。

## 工具白名单

- `ask_user`

## 执行流程

1. 从用户输入中识别企业名称
2. 判断是否为简称/俗称/歧义名
3. 若是，调用 `ask_user` 向用户确认完整全称
4. 若否（用户已提供完整全称），直接结束

## 输入槽位

- `customer_name`：用户请求中的企业名称

## 强约束

1. 仅当企业名称为简称/俗称/歧义名时才发起确认
2. 用户已提供完整全称时跳过确认，直接结束
3. 确认结果写入 session，供后续 Skill 使用
