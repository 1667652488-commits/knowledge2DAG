- **超范围 / 前后矛盾 / 集团混淆**：泛化边界 case，复现率 50–75%，未复现的逐条确认是"agent 真对了"还是"评估器漏判"。
- **评估器初判的可信度**：对"过程错但结果有"（credit123 结果展示）和"技术失败盖住业务问题"（邮件 sandbox）两类场景容易误判，**必须 golden + 人工看 trace 复核**，不能只信 is_pass。
- **后续**：补跑 golden，用 expected_behavior+result 对照评估器 is_pass + trace 实证，得三视角复现率。
